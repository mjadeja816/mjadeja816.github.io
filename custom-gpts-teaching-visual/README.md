# Interactive Visual for Understanding Custom GPTs

This is a standalone teaching demonstration for Dr. Mahipal Jadeja's session, "Building Custom GPTs: Designing Personalized AI Assistants."

## Files

- `index.html`: Main webpage.
- `styles.css`: Visual design and responsive layout.
- `script.js`: Presentation controls and interactions.

## How to use

Open `index.html` in any modern browser. No server or internet connection is required for the visual itself.

## Presenter controls

- `Next` and `Previous`: Move through the customization layer.
- `Play`: Automatic presentation mode.
- `Restart`: Return to the first step.
- `Reduce Motion`: Disable animation.
- `Full Screen`: Use for classroom projection.
- Keyboard: Right arrow or space for next, left arrow for previous, `P` for play or pause, `R` to restart.

## Website placement

The folder can be uploaded as a static page under a teaching demonstrations section on `mahipaljadeja.com`.
